# StampaceCharmingEssential

Nuovo progetto separato dal template `StampaceCharming`.

Obiettivo:
- esperienza mobile-first
- tono elegante e minimale
- struttura semplice, facile da personalizzare

Stack:
- HTML
- CSS
- JavaScript vanilla
- Supabase
- GitHub Pages

Verifiche:

```bash
npm run check
```

Il file `template.json` usa il formato canonico con `footer`, `enabledLocales` e `locales`.
Supabase resta la sorgente live; `template.json` e il default in `content.js` sono fallback.

Avvio locale:

```bash
python3 -m http.server 4173
```

Poi apri:

```text
http://127.0.0.1:4173
```
